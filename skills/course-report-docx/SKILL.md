# 课程报告 / 毕业论文 Word 文档

这个技能把一份高校课程报告模板的全部排版规范固化下来，用于撰写和排版课程设计报告、毕业论文、实验报告等长文档。

它的价值在于：学校对这类文档的格式要求非常琐碎（标题字号、题注位置、页码分节、目录收录范围……），任何一项不达标都可能被要求返工重排。把规范前置到写作阶段，比写完再逐项对照检查要省力得多。

**适用范围**：需要分章分节、带封面/摘要/目录/参考文献的正式 Word 报告。若只是一页纸的实验小结或没有格式要求的草稿，不必使用本技能。

## 工作流程

### 第 1 步：确认任务要素

先弄清楚要产出的东西，再动手写。需要确认的要素：

1. **报告类型与题目** —— 课程设计报告 / 毕业论文 / 实验报告；具体课题名称（会写进封面的 `{{REPORT_TITLE}}` 占位符）
2. **课程名称** —— 用于正文页眉（模板里是占位符 `XXXXXXX课程报告`）
3. **封面信息** —— 日期（`{{DATE}}` 占位符）+ 姓名、学号、学院、专业、年级（**固定文字**，需手改，见下方说明）
4. **章节要求** —— 学校/老师是否给了指定章节结构；有无页数、字数要求
5. **输出位置** —— 存到哪个目录、文件名怎么起

如果用户没有明确给出，就把要素列成一张简短清单一次性问清楚，不要逐条追问。

**关于封面**：模板的封面已按最终版式固化，日常只需要换**报告题目**和**日期**两项。封面上的姓名/学号/学院/专业/年级是固定文字（不是占位符），换人时打开文档手改这 5 行即可——之所以不做成占位符，是因为表格单元格里的占位符替换容易把单元格格式一起冲掉，而写字的人其实只有你一个。

### 第 2 步：选择生成路径

按下面顺序选择，**优先复用模板**，因为它能最大程度保证格式（分节、页码格式、域、样式）零偏差：

| 路径 | 适用场景 | 做法 |
|---|---|---|
| A. 复用模板（首选） | 用户需要完整格式保真 | ① 跑 `scripts/prepare_report.py` 生成"干净起点"；② 人工删除示例插图/表格/定义定理示例/算法示例框，填写封面信息；③ 填入正文 |
| B. 从头生成 | 拿不到模板资产，或用户只要一份纯内容草稿 | 用当前环境可用的 Word / OOXML 文档生成能力新建 .docx，然后**逐项**按 `references/format-spec.md` 设置页面、样式、编号与题注 |

路径 A 的第 ① 步用脚本完成，它处理的是"机械但容易漏"的那批操作：

```bash
python scripts/prepare_report.py assets/course-report-template.docx 输出.docx \
    --course "数据库课程报告" \
    --title "基于 REA 的 AI 辅助逆向分析实验开题报告" \
    --date "2026年10月"
```

- 删掉所有红色（FF0000）说明文字，以及因此变空的段落
- 删掉批注部件与修订痕迹（同时清掉正文里的批注锚点）
- 把页眉里的 `XXXXXXX课程报告` 换成真实课程名
- 把封面的 `{{REPORT_TITLE}}` / `{{DATE}}` 换成真实题目与日期
- 统一题注格式（居中、加粗、不缩进；表与算法题注设"与下段同页"，图题注不设）
- 给紧邻图题注的图片段落补"与下段同页"
- 给无样式的正文段落补齐小四 12pt（模板的 Normal 样式是五号，不补的话直接打字会得到五号字）

`--title` / `--date` 省略时占位符会留在文档里，脚本会在结尾提醒；`check_report.py` 也会因此报 FAIL。

**脚本不做的那部分必须人工完成**：删除示例插图、示例表格、定义/定理示例、算法示例框，以及改封面上的姓名/学号/学院/专业/年级。这些没有可靠的自动判定依据——"哪张表是示例"只有人知道。留一两条示例内容在正式报告里是很显眼的失误。

路径 B 的关键动作：标题的多级编号（`第X章` / `X.X` / `X.X.X`）和题注的自动编号必须用 Word 的**多级列表 + 域**实现，不要手打序号——手打的编号在增删章节后必然错位，而且无法生成自动目录。

### 第 3 步：写内容

按照 `references/writing-guide.md` 里的章节骨架与写作要点组织正文：

- 先搭骨架（章、节、小节标题），再填内容
- 摘要、绪论、结束语这三处最容易写得空泛，重点参考写作指南里的要点
- 图表公式一定要有编号**和**名称，且正文中要用交叉引用提到它

### 第 4 步：套格式

按 `references/format-spec.md` 执行。如果只记三条，记这三条：

1. **正文**：宋体小四（12 pt）、1.5 倍行距、两端对齐、首行缩进 2 字符
2. **题注**：图题注在图**下方**、表题注在表**上方**、算法题注在算法框**上方**；三类题注**统一**为宋体五号（10.5 pt）+ **加粗** + **居中** + **不首行缩进**
3. **分节**：封面、摘要、目录、正文各自独立分节——这是页码和页眉能区分开的前提

### 第 5 步：交付前自检

**三级检查，从便宜到贵依次跑。**

**① XML 级（必做，秒级）**

```bash
python scripts/check_report.py 输出.docx
```

逐项核对页面与分节、页码与页眉、正文格式、标题、题注、表格与域、结构完整性、残留清理，输出 PASS / WARN / FAIL 三类结果（退出码 0 = 没有 FAIL）。**FAIL 必须修掉再交付**，WARN 需要人判断。

其中"结构完整性"这一组专门拦截会让 Word 打不开的硬伤：单元格里没有段落、`body` 末尾缺少 `sectPr`、批注部件删了但正文锚点还在。这些问题的表现都是 Word 弹"文件可能已经损坏"。

**② 渲染级（可选，需要本机装有 Microsoft Word）**

```powershell
powershell -ExecutionPolicy Bypass -File scripts/render_check.ps1 -Path 输出.docx
```

XML 检查看不出"格式乱跑"——分页落在哪、有没有多出一页空白、表格有没有被切断、图和题注是不是被拆到两页。这一步让 Word 真正排一遍版再测量：

- 封面是否恰好 1 页（撑破版心会变成 2 页）
- 封面是否真的没有页码（实测页脚，而不是只看 XML）
- 封面纵向顺序是否正常：题目 → 信息表 → 日期自上而下依次排开
- 有没有空白页
- 表格是否被分页切断
- 图与题注是否被分页拆开
- 有没有"错误！"字样的域错误（目录未更新、交叉引用失效）

没装 Word 时脚本会打印提示并返回 0，不会阻断流程，所以可以放心地放进自动化里。

**③ 人工确认（脚本判断不了的）**

- 图是否用专业工具绘制后插入、公式是否用公式编辑器生成（不能贴图）
- 表格跨页时是否启用了"重复标题行"
- 正文是否用交叉引用提到了每一张图表公式
- 内容层面：摘要是否回答了"为什么做/做什么/难在哪/怎么做/做成啥样"

下面是完整的人工核对清单。

## 格式速查

完整的规范见 `references/format-spec.md`。以下是最容易出错的高频项。

### 页面与分节

| 节 | 内容 | 上下边距 | 左右边距 | 页眉 | 页码 |
|---|---|---|---|---|---|
| 1 | 封面 | 2.54 cm | 3.17 cm | 无 | 无 |
| 2 | 中文摘要 + ABSTRACT | 2.54 cm | 3.17 cm | 无（空页眉） | 无 |
| 3 | 目录 | 2.54 cm | 3.17 cm | 无 | 罗马数字 I、II、III |
| 4 | 正文各章 + 参考文献 | **2.5 cm** | **3.0 cm** | 有（"课程名课程报告"居中，带下框线） | 阿拉伯数字，从 1 开始 |

纸张 A4 纵向；页眉距边界 1.5 cm，页脚距边界 1.75 cm。

### 字体与字号

| 用途 | 字体 | 字号 | 加粗 |
|---|---|---|---|
| 正文、摘要正文 | 宋体 | 小四 12 pt | 否 |
| 英文摘要 | Times New Roman | 小四 12 pt | 否 |
| 一级标题（章） | 黑体 | 三号 16 pt | 是 |
| 二级标题（节） | 黑体 | 14 pt | 是 |
| 三级标题（小节） | 黑体 | 小四 12 pt | 是 |
| 图/表/算法题注 | 宋体 | 五号 10.5 pt | **一律加粗**；居中、不缩进 |
| 表内文字 | 宋体 | 五号 10.5 pt | 否 |
| 算法框内代码 | Times New Roman | 五号 10.5 pt | 关键字加粗、变量斜体 |
| 参考文献条目 | 宋体 | 五号 10.5 pt | 否 |
| 摘要/目录/参考文献大标题 | 黑体 | 18 pt | 是 |
| 封面"课程报告" | 方正大黑简体 | 62 pt | 否 |

### 封面版式（已固化在模板里）

自上而下依次是：

| 元素 | 格式 |
|---|---|
| 学校 Logo | 内嵌图片，10.0 × 6.0 cm，居中 |
| "课程报告" | 方正大黑简体 62 pt，不加粗，居中 |
| 题目行 | `题目：{{REPORT_TITLE}}`，宋体 16 pt，加粗，居中 |
| 信息表 | **5 行 × 2 列浮动表格**（整体无框线，页级锚定）。标签 `姓    名：` `学    号：` `学    院：` `专    业：` `年    级：` 为楷体 16 pt 加粗；值为 14 pt 加粗 |
| 日期行 | `{{DATE}}`，楷体 16 pt 加粗，居中，位于页面下部 |

两个占位符由 `prepare_report.py --title / --date` 填充；姓名等 5 项是固定文字，换人时手改。

填写区的那条横线**来自单元格底边线（`tcBorders/bottom`，0.5 磅），不是文字下划线**——整张表的 `tblBorders` 六条边全是 `none`，只有第 2 列各单元格带底边线。想调线就去改单元格边框，别给文字加 `U`，两者叠加会变双线。

**封面节不得有页脚引用和 `pgNumType`** —— 带上任何一个，封面都会印出页码。模板已在合并时清掉，`check_report.py` 会硬性拦截复发。

### 标题格式

| 层级 | 编号 | 对齐 | 段前 | 段后 | 行距 | 分页 |
|---|---|---|---|---|---|---|
| 一级（章） | 第X章 | 居中 | 12.45 pt | 7.8 pt | 1.5 倍 | **段前分页** |
| 二级（节） | X.X | 左 | 7.8 pt | 7.8 pt | 单倍 | 不自动分页 |
| 三级（小节） | X.X.X | 左 | 7.8 pt | 7.8 pt | 单倍 | 不自动分页 |
| 参考文献（无编号） | — | 居中 | 12.45 pt | 7.8 pt | 1.5 倍 | **段前分页** |

### 题注编号（用域，不要手打）

- 图：`STYLEREF 1 \s` + 不换行连字符 + `SEQ 图 \* ARABIC \s 1` → `图2-1 流程图`
- 表：`STYLEREF 1 \s` + 不换行连字符 + `SEQ 表 \* ARABIC \s 1` → `表2-1 示范表`
- 公式：章号 + `SEQ 公式 \* ARABIC \s 1`，用中文全角括号（2-1）写在公式同行右侧
- 算法：章号 + `SEQ 代码 \* ARABIC \s 1` → `算法3-1`

### 几个容易忽略的硬性要求

- 图必须用专业工具画好后**作为图片插入**，不能在 Word 里画，也不能用截屏当公式
- 公式必须用"插入公式"或公式编辑器生成，不能贴图
- 表格**不可跨页**；确实跨页时启用"重复标题行"
- 目录只收录 1~3 级标题，**不含**"摘要""ABSTRACT""目录"本身
- 表题注段落设"与下段同页"；图与其题注不被分页断开靠的是**图片段落**设"与下段同页"

## 交付前自检清单

**结构**
- [ ] 封面、摘要、目录、正文各自独立分节（共 5 节，末节为空节）
- [ ] 每章标题段前分页；参考文献标题段前分页
- [ ] 目录由 `TOC \o "1-3" \h \z \u` 域自动生成，更新域后页码正确

**页码与页眉**
- [ ] 封面、摘要页无页码
- [ ] 目录页用罗马数字，从 I 开始
- [ ] 正文页码用阿拉伯数字，从 1 开始
- [ ] 页眉只在正文及以后出现；页眉文字已替换为真实课程名，不是 `XXXXXXX课程报告`

**文字**
- [ ] 正文全部宋体小四、1.5 倍行距、两端对齐、首行缩进 2 字符
- [ ] 标题使用 Word 内置"标题 1/2/3"样式并挂接多级列表（不是手工加粗的大字）
- [ ] 没有残留的红色说明文字
- [ ] 没有残留的批注与修订痕迹
- [ ] 封面：题目与日期已替换（`{{REPORT_TITLE}}` / `{{DATE}}` 不再出现），姓名/学号/学院/专业/年级已手改
- [ ] 封面只有 1 页，且没有页码

**图表公式**
- [ ] 每张图有编号**和**名称，题注在图下方、居中、五号加粗、不缩进
- [ ] 每张表有编号**和**名称，题注在表上方、居中、五号加粗、不缩进；表题注段落设"与下段同页"
- [ ] 算法题注在算法框上方、居中、五号加粗、不缩进（与图表题注同格式）
- [ ] 表内文字五号、单倍行距；表格未跨页
- [ ] 算法框内代码为五号 10.5 pt（不是模板示例里的 9 pt）
- [ ] 正文中所有图表公式都用交叉引用提及（"如图2-1所示"），序号可随内容自动更新

**参考文献**
- [ ] 用尾注（位置为"节末尾"）插入，序号加中括号并设为上标
- [ ] 条目为宋体五号、1.5 倍行距、两端对齐、悬挂缩进 2 字符
- [ ] 多篇合并时按 `[1]`、`[1,2]`、`[1-3]` 形式书写

## 兼容性说明

本技能设计成可被任意能读写文件的 Agent / 应用使用：

- **不依赖任何第三方 Python 包**：两个 Python 脚本只用 `zipfile` + `xml.etree`，任何 Python 3 环境都能直接跑，不需要 pip 安装
- **脚本按"必做 / 可选"分层**：`prepare_report.py` 与 `check_report.py` 是纯 Python、跨平台的必做项；`render_check.ps1` 依赖 Windows + Microsoft Word，属可选增强，检测不到 Word 时自动跳过并返回 0，不会让自动化流水线失败
- **不绑定特定平台**：路径 B 写的是"当前环境可用的 Word / OOXML 文档生成能力"，没有绑定某个产品的专有 API
- **引用全部是相对技能目录的路径**，整体搬运技能文件夹不会断链
- **资产文件名是纯 ASCII**（`course-report-template.docx`），避免中文名在跨系统传输时被转码破坏
- **输出的 .docx 是标准 OOXML**：重新序列化时会补回原文件的全部命名空间声明，并保证 `pPr` / `rPr` 子元素顺序符合 ECMA-376；删批注时会同时清掉正文锚点、保证单元格都留有段落，WPS / Word / LibreOffice 都能正常打开
- **字体已内嵌**：方正大黑简体随模板内嵌（`word/fonts/font_course_title.odttf` + `embedTrueTypeFonts`），没装这个字体的机器上封面标题也不会退化成宋体

> **已知非标准字段**：frontmatter 里的 `agent_created: true` 是 WorkBuddy 的本地约定（平台用它判断能否改写该技能）。它不在 Anthropic 官方 skill 规范的允许字段内。**若要把本技能发布到其他平台、或跑官方 `quick_validate.py`，删掉这一行即可通过校验**，其余部分完全合规。

## 维护须知（改脚本前必读）

这三个坑都实际踩过，症状都是 Word 弹"文件可能已经损坏"或封面版式突然崩坏，而 XML 结构检查看不出来。

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 删掉 `comments.xml` 但正文还留着 `commentRangeStart` / `commentRangeEnd` / `commentReference` 锚点 | Word 打开即报损坏 | 删批注部件的同时清掉正文里的 66 个锚点（`strip_comment_markers`），并清理被摘空的 `w:r` |
| 清理空段落时把表格单元格里仅剩的那个段落也删了 | `w:tc` 没有子段落，Word 报损坏 | 任何删除前先判断"是不是所属 `w:tc` / `txbxContent` 里最后一个 `w:p`"，是就保留 |
| 清理空段落时把封面撑版的 22 个空段落一起删了 | 封面挤成一团，日期从 y=717 顶到 y=373，与信息表重叠 | 只删"因删除红字才变空"的段落（记录红字所在段落再判断），模板本来就有意留空的一律不动 |

改完脚本务必跑一次 `render_check.ps1`：`check_report.py` 全 PASS 并不能证明 Word 一定打得开。

- `references/writing-guide.md` —— 章节骨架与写作要求（摘要五问、绪论三节、文献综述规范、图表公式写法、结束语要点、常见失分点）。
- `assets/course-report-template.docx` —— 唯一的主模板（499 KB）。含完整样式表、5 个分节、页眉页脚、题注域、多级编号、内嵌方正大黑简体，以及**已按最终版式固化好的封面**。正文里的红色文字是模板作者的排版说明，属于示例内容，`prepare_report.py` 会自动删除。
- `scripts/prepare_report.py` —— 模板预处理：从模板生成一份"干净起点"（删红色说明文字与批注锚点、删批注部件与修订、替换页眉占位符与封面题目/日期、统一题注格式、补"与下段同页"、补正文小四字号）。源文件只读，输出到新路径；可重复执行且结果一致。
- `scripts/check_report.py` —— XML 级格式自检：逐项核对页面分节、页码页眉、正文格式、标题、题注、表格与域、结构完整性、残留清理，输出 PASS / WARN / FAIL，退出码 0 表示无 FAIL。适合放在"改一版 → 跑一次"的循环里。
- `scripts/render_check.ps1` —— 渲染级自检（可选）：调用 Microsoft Word 实际排版，测页数、空白页、封面是否 1 页、封面是否漏出页码、表格是否跨页、图与题注是否被拆开、有无域错误。加 `-Pdf x.pdf` 可同时导出 PDF 供肉眼复核。
